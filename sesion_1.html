Introducción a tidyverse

Tidyverse

  • Una colección de paquetes de R 📦s desarrollados por H. Wickham y colaboradores en Posit.

Tidyverse es una colección de paquetes de R 📦

  • ggplot2 - visualización

  • dplyr, tidyr - manipulación de datos

  • purrr - programación avanzada (funciones y “loops”)

  • readr - importar datos

  • tibble - formato mejorado de data.frame

  • forcats - trabajar con factores

  • stringr - trabajar con cadenas de caracteres

Tidyverse

  • Un marco para gestionar datos que busca hacer mucho más fáciles los pasos de limpieza y preparación

  • Características principales de un conjunto de datos “tidy”:

    • Cada variable es una columna
    • Cada observación es una fila
    • Cada valor está en una celda distinta

Análisis descriptivo reproducible con gtsummary

¿Por qué gtsummary? 🩺

  • En investigación médica casi todo manuscrito comienza con la “Tabla 1”: características de la muestra.
  • Hacer esa tabla a mano en Word es lento, propenso a errores y no es reproducible.
  • gtsummary genera tablas descriptivas listas para publicación desde un solo bloque de código.
  • Es el estándar de facto en R para reportes clínicos.

Una tabla descriptiva en una línea

install.packages("gtsummary")
library(gtsummary)

Personalizando etiquetas para publicación

covid_testing %>%
    select(age, gender, drive_thru_ind, ct_result, result) %>%
    tbl_summary(
        by = result,
        label = list(
            age ~ "Edad (años)",
            gender ~ "Sexo",
            drive_thru_ind ~ "Atención drive-thru",
            ct_result ~ "Valor Ct (PCR)"
        ),
        missing_text = "Datos faltantes"
    ) %>%
    add_p() %>%
    add_overall() %>%
    bold_labels() %>%

Exportar la tabla a Word, PDF o HTML

  • Las tablas de gtsummary se renderizan automáticamente al formato de salida de tu Quarto (HTML, Word o PDF).
  • También puedes exportarlas a un archivo independiente:
mi_tabla %>%
    as_gt() %>%
    gt::gtsave("tabla1.docx") # o "tabla1.html", "tabla1.pdf"
